# VIGAM Labs — Official Company Website

A minimalist, high-craft company website for **VIGAM Labs** — an ethical, local-first artificial intelligence laboratory founded by **Shivam Thakur** and **Vignesh A. Palan** (2026 M.Tech in Artificial Intelligence & Decision Science graduates from Manipal Institute of Technology, MIT Manipal).

## Philosophy & Core Tenets

- **100% Local Inference**: All AI pipelines run directly on user hardware (CPU / Edge GPU). Zero round-trip cloud API dependencies.
- **Zero Subscriptions**: Fair, perpetual software licensing. Buy once, own forever.
- **Air-Gapped & Offline Capable**: Zero data transmission. Audio, documents, and research never leave client machines.
- **Zero Telemetry**: No tracking cookies, no background surveillance, no account walls.

## Local Development & Preview

This website is engineered with zero runtime framework bloat (vanilla HTML5, CSS3 with tokens, and modern JavaScript).

To preview locally:
```bash
# Python
python -m http.server 3000

# or Node / npx
npx serve
```
Open `http://localhost:3000` in your browser.
